# M4-Mojito：超短期模型架构讨论稿

初稿：2026-10-15；实现更新：2026-10-19。M4-Mojito 第一版代码已落地，已完成合成数据前向、反向、训练与权重重载验证，尚未开展真实数据效果评估。本文包含后续实验设想，当前实现范围以模型目录的 README 为准。

当前实现：无站点 ID/地理特征的共享主干；保留多尺度历史、天气条件 query、近期旁路、有限值 mask 和因果尾部扰动。复用 UnifiedDataset、ModelOutput、模型注册和通用推理。正式业务口径尚未固定，独立训练入口暂用验证集 weighted MAE 选择权重。省级气象聚合继续由上游负责。

## 1. 目标与范围

每 15 分钟起报一次，给定起报时刻 t 可获得的数据，一次预测 t+15min 至 t+4h，共 16 点。起报频率暂按 15 分钟设计；若线上不同，数据与评估按实际频率调整。

延续 M4 的 patch 表示和跨变量联合注意力，重构历史/未来接口和输出头。模型直接输出点预测，不要求 Chronos/TimesFM 存在，不用未来实测构造任何输入。

用户已确认：站级和省级都需要；训练历史功率可靠，但推理侧是否缺失、缺失长度及填补方式不可感知。因此不能假设存在真实的修补mask或“距最近可靠观测的时间”。尚待确认：考核标签究竟是实发功率还是治理后的可用功率、最终指标口径。

主干按单个实体样本设计：实体可以是站或省；建议共用架构实现，分别准备输入、训练权重和评价，首轮不混合站/省训练。站级可多站共训；省级直接预测省总功率，不自动等同于站级预测求和。

### 已确认条件带来的设计修订

- 显式NaN/缺列是可检测的“数值缺失”；已被填成有限值的隐性缺失不一定可识别。数值存在不能当作实测可靠。
- 默认输入不使用真实质量标签或可靠观测age；这些只作为将来上游可提供时的可选信息。
- 训练必须比较干净输入与受扰动输入，尤其要模拟“填补后看起来正常、没有mask提示”的尾部数据；增强类别和概率是实验设置，不是对线上发生率的估计。
- 不把疑似异常强制改写成正常功率。真实限电、停机、快速云变化也可能造成平段或突变。

## 2. 和旧 M4 的关系

| 部分 | 旧 M4 默认路径 | Mojito 提案 |
|---|---|---|
| 时间输入 | 历史672与未来192拼接 | 历史672与未来16分开建模 |
| 功率先验 | Chronos直接接到功率通道后 | 可选独立未来特征，缺失有mask，首轮关闭 |
| patch | 全天96点一个patch | 周历史96点/patch + 最近一天4点/patch |
| 变量交互 | 变量×patch联合注意力 | 保留，并加入变量/尺度/时间标记 |
| 主干 | 4层、256宽、BatchNorm | 起始提案3层、128宽、Pre-LayerNorm |
| 输出 | 全展平→256→256→64→H | 16个天气条件query→共享逐步head |
| 尺度 | 历史和先验一起RevIN | 功率按可靠容量，天气固定尺度；RevIN留作消融 |
| 缺测 | 依赖上游填好 | 显式缺失mask＋无质量标记的隐性填补扰动训练 |

旧 M4 的64维末端对192点有较强表示约束，但对16点不构成相同的输出秩瓶颈。新解码器的主要理由是目标时刻对齐、天气直达、避免flatten参数随通道数和patch数增长，而非声称64维不足以输出16点。

这是新训练架构，不兼容旧checkpoint。保留现有m4实现作为基线；代码位于 `forecast_backbones/m4_mojito/`，展示名为 `M4-Mojito`。

## 3. 数据契约

以B表示batch，C_h表示历史数值通道数，C_f表示未来天气通道数。

| 输入 | 模型内形状 | 说明 |
|---|---|---|
| 历史数值 | [B,672,C_h] | 时间从旧到新，末点名义对应t |
| 历史有限值mask | [B,672,C_h] | 模型收到数据时记录，仅能识别仍显式缺失的值 |
| 历史质量标记 | [B,672,C_h,Q]，可选 | 实测/修补/未知来源，不应凭有限值猜测已修补 |
| 未来天气 | [B,16,C_f] | 第h点对应t+h×15min |
| 未来天气mask | [B,16,C_f] | 不同源/字段分别标记 |
| 时间特征 | 历史[B,672,T]、未来[B,16,T] | 时刻sin/cos、年内日sin/cos；日历按Asia/Shanghai |
| 容量 | [B] | 必须有限且>0，单位与目标一致，来源可追溯 |
| 当前状态摘要 | [B,S] | 最近有限功率、近段统计、有限值比例；不宣称可靠 |
| 未来外部预测 | [B,16,K]，可选 | 对应时间、来源和mask明确，第一版关闭 |
| labels | [B,16] | 只供loss与评估，缺测单独mask |

默认历史通道为 observe_power、general_ghi、general_temp，未来为general_ghi_predict、general_temp_predict。保留配置映射和气象来源语义：历史天气列不必然是实测，不能仅凭列名认定来源。

首轮使用与旧M4相同的天气源，避免把输入变化和架构变化混在一起；后续测试多源独立通道。

站级适配器：本站历史功率、对应站点NWP、本站可信容量，按站形成样本；站级模型多站共训。省级适配器：省总功率、业务口径一致的省级容量、各站/区域NWP的容量加权特征，先沿用已有TabM的聚合逻辑建立基线。

省级气象平均值可能隐藏区域差异，可在独立实验中加同源同变量的容量加权标准差及有效容量覆盖率（有数据站点容量/预期站点总容量）。覆盖率不能把分母也缩到当前有数据的站点，否则缺站会被隐藏。区域分组token或空间attention放在后续；加权离散度是可选信息，不预设一定增益。没有站点组成元数据时覆盖率记不可用，不伪造完整覆盖。

省级聚合数值通道增加时，C_h和token数同步变化；94个token仅对应三通道初始例子。两层级各自训练的checkpoint可以采用不同字段配置，但均输出[B,16]并复用相同核心类。

### 多站混合训练与新站推理（最终首版方案）

用户补充：训练混合一百多个站点，站点位于同一省份且相距较近，还需支持未参与训练的新站。第一版不使用站点 ID、经纬度或太阳位置，通过本站历史功率和天气的共同上下文进行适配；站名只用于数据对齐和评价。

- 相邻站点的太阳几何可能非常接近，无法充分表达设备、朝向、损耗和限电差异；不把坐标的小数差异用作隐式站号。
- 历史编码器同时表示过去几天的天气—功率关系和近期状态，解码器按目标时刻提取；不额外增加站点识别网络，也不保证七天历史足以识别所有物理差异。
- 新站有历史时直接走共享计算路径，无需创建新站点向量；短历史左侧补缺失，保持末点对应起报时间。无功率历史是另一种冷启动条件，首版仅输出质量标记，业务降级与预测效果需单独验证。
- 训练采样检查各站有效样本数量，比较按样本自然抽样与适度站点均衡，避免长记录站垄断训练，也避免对少量或低质量站过采样。
- 评价分为已知站未来时间段和完整留出站；留出站不参与训练，推理可使用起报前可获得的本站历史，归一化及特征拟合不使用其未来目标。报告按站宏平均、正式业务汇总与最差站退化，并交叉检查历史尾部受扰动场景。

站点 ID 和太阳位置仅留作后续对照设想，当前不实现相关分支。太阳位置的候选作用是日照几何条件，并非区分站点；若未来增加 ID，未知站处理及站点留出评估仍须单独设计，不能把零向量视为获得了新站个性。

站级、省级共用核心结构，分别训练权重。省级使用上游已聚合的天气、总功率和对应容量。

### 数据时间与质量

- 末点缺失时保持原时间轴：t位置仍代表t，不能把t-30min的观测向右移动冒充t。
- 默认仅计算 `last_finite_age`，表示最近有限数值距起报的步数；上游填补后它可能等于0，不能解释为没有延迟或修补。真实观测age须由可信元数据提供，缺省不启用。
- 无质量元数据时，训练干净数据和隐性填补数据均记unknown，不把模拟扰动的位置、长度、方法告知模型。固定屏蔽末2/4点只作为与现有TabM对比的独立方案，不假定足以覆盖未知缺失长度。
- 模型收到的显式缺失使用有限占位值与mask，不能把NaN带入线性层/注意力；若上游已填零且无标记，则真实零与填补零可能不可区分，不能承诺恢复其来源。
- 历史和天气预报均必须来自起报时刻可获得的版本。后验修补、后发布NWP和跨越起报边界的插值不能混进训练输入。
- 保留 `nwp_init_time`/`available_time`/`target_time`（若源数据提供），预报age可加入未来特征。没有这些字段时不伪造“已核实可用”状态。

## 4. 归一化

默认功率与标签除以同一容量C，输入保留真实相对幅度。未来提示若为功率，同样除以C。容量不能从未来标签估计。

天气固定尺度，例如 GHI/1000、(温度−15)/15，只是初始数值尺度，不代表强制裁剪范围；先统一单位（尤其K与℃、辐射通量与累积量）。可学习或数据驱动的统计量只在训练集拟合并随checkpoint保存。

不对历史功率和未来预测先验混合计算统计量。第一版不启用RevIN，后续单独测试历史mask-aware RevIN，并把均值、标准差和容量归一幅度旁路传给head，以保留绝对量信息。

选择容量归一是设计假设，不把它预设为优于旧M4；归一化变化须单独消融。

## 5. 多尺度历史tokenizer

用同一历史表的两种视图：

- 慢尺度：672点，patch=96，stride=96，每个变量7个token。
- 快尺度：最后96点，patch=4，stride=4，每个变量24个token。

每个patch把归一数值、逐点可用mask和可选质量标记一起投影到d=128；相同尺度不同变量共享投影，两个尺度因输入宽度不同使用独立投影。

`token = projection(values, masks, quality) + variable_embedding + scale_embedding + time_embedding`

时间embedding依据patch在真实历史轴上的位置和时间特征生成，不能把慢/快两组视图误认为首尾相接的新时间轴。最近一天在两个尺度重复出现是有意的多尺度表示，不额外重复计算监督loss。

默认C_h=3时：慢21个＋快72个＝93个历史token。再加入1个由当前状态摘要编码的STATE token，得到[B,94,128]。

STATE包含最近有限功率、last_finite_age、近4/16点均值与变化统计、有限值比例；还可加入连续相同值长度、与前日同时刻及天气的偏离等可计算描述。它们只是数值特征，不是可靠性标签；平段可以是真实限电或夜间。样本不足时给mask，不能用未知的真实质量筛选观测。

完全无有效数值的普通patch在attention中作为key被mask；STATE token始终存在用于避免all-masked softmax，但“存在”不表示数据有效。全历史功率不可用的样本应打质量标记并进入预先定义的业务降级路径，不默认当成正常成功预测。

## 6. M4联合历史编码器

拼接所有变量和尺度的token，沿用M4的跨变量、跨时间自注意力。

初始参数：d_model=128、heads=4、layers=3、d_ff=512、dropout=0.1、Pre-LayerNorm、GELU。相较旧版减少宽度是为了控制多尺度token增加的成本，不是已验证的最优配置。

每层：

`Z ← Z + Dropout(MHA(LN(Z)))`

`Z ← Z + Dropout(FFN(LN(Z)))`

所有历史都在起报前可用，默认双向attention，无需时间因果mask。padding/缺测mask仍必须生效。输出memory M∈[B,94,128]。

第一版不复制旧版跨层attention score累加，作为独立消融选项保留设计位置；不同时引入MoE、空间图网络或复杂门控。

## 7. 16个天气条件query

每个未来点单独构造query：

`q_h = MLP([future_weather_h, weather_mask_h, time_h, lead_h, forecast_age_h, optional_hint_h]) + horizon_embedding[h]`

不存在的可选字段不伪造真实值，采用明确mask。Q∈[B,16,128]。

这一设计区别于仅使用16个可学习空query：每个query从一开始就知道自己的天气条件和目标时刻。

## 8. 目标时刻解码器

使用2层Pre-LN decoder，每层包括：

1. 16个未来query之间self-attention，交流未来天气变化；
2. query对历史memory的cross-attention，提取相关历史状态；
3. FFN残差块。

第一版顺序为self-attention→cross-attention→FFN，输出D∈[B,16,128]。不输入未来功率真值，不做teacher forcing，也不把前一步预测递归输入下一步。

未来天气在t时已可获得，所以未来query之间允许双向attention；这不等于能访问未来实测。该设计仍需以可用批次为准验证数据。

## 9. 共享逐步输出头与近期信息旁路

从最近16个历史功率位置构造state_raw：归一功率、有限值mask、last_finite_age；质量信息默认unknown。原时间位置不变。与未来每个时刻共享拼接，保留最近变化的直接路径。

训练扰动必须先作用于原始历史功率，再派生快/慢patch、STATE及state_raw，所有路径读取同一份受扰动历史，防止旁路泄露干净尾部。若以后加入依赖历史功率生成的外部预测先验，也必须同步重新生成、扰动或关闭，不能让它暗中携带干净尾部。

`u_h = [D_h, scaled_future_weather_h, weather_mask_h, time_h, state_raw, optional_hint_h]`

`p_norm_h = Linear(GELU(Linear(u_h)))`

中间宽度64，最后输出1；head在16个h之间共享权重，horizon_embedding允许不同时效行为不同。64是每个时刻的隐藏宽度，不是整条曲线共用一个64维瓶颈。

输出 logits = C×p_norm，形状[B,16]。第一版不加硬sigmoid上限、不按固定钟表时间强制夜间归零、不强制所有时效贴近最后实测。全点训练、夜间同样监督；业务裁剪策略单独配置和报告。

第一版也不加入复杂的持久性门控/多基线混合，不把末点设成强制持久性锚点。可选后续实验：近期旁路门控、Chronos/TimesFM提示、或者各时效独立的小head。门控仅是通过预测损失学出的信息使用权重，不能当成校准过的“数据可靠概率”；其输入只含线上可获得的数值特征，不能使用模拟扰动真值。上述实验分别回答不同问题，不一次全加。

## 10. 损失与指标

默认候选为容量口径的归一化绝对误差：

`e[b,h] = abs(p_norm[b,h] - y[b,h]/C[b]) / max(y[b,h]/C[b], 0.2)`

每行在有效标签上按16个时效等权平均，再对有效行求均值。掩码前先替换无效标签为有限占位，避免NaN×0；一行无有效标签不参与loss。当前训练入口预先排除全部目标无效的行，直接前向遇到整个batch无有效标签时明确报错，避免零损失仍触发优化器更新。输入质量异常与标签缺失分别管理。

这与现有TabM的weighted_mae分母形式接近，但不宣称等于完整业务评分：目标时刻对齐、站日月聚合、时段、缺失惩罚等另行计算。第一版斜率loss、平滑loss、分位loss权重均为0，防止未经验证就偏向平滑曲线。

当前工程两份指标不能直接混用：

- NextGen `pipelines/nanwang_metric.py` 默认筛选06:15–20:00，并可要求16个lead齐全，日汇总使用固定96分母。
- `province_tabm_engineered/evaluation.py` 使用整日96×16格点并显式处理缺失预测。

实现前必须固定目标实体对应的正式评价口径，不把两者同名分数混为一谈。预测结果应保存为issue_time、target_time、horizon、entity、prediction、truth、quality，以便按同一目标时刻汇集16个提前量。

## 11. 训练方案（初始建议）

AdamW，lr=3e-4，weight_decay=1e-3，cosine，warmup占总步数5%，grad_clip=1，初始global batch=256。优先fp32建立数值基线，混合精度另测。显式在模型构造前设置Python/NumPy/Torch种子，多卡增强随机流分开。

按固定验证频率保存业务指标最优权重，附加h1/h4/h8/h16、按站与按季节、白天/夜间、爬坡日、数据延迟切片。早停patience=8次验证作为初值，不把epochs视为固定最终预算。

数据采用时间块及站点留出；按实际输入和标签覆盖验证隔离边界。第一版可复用旧M4的保守切分便于配对比较，但不能因为标签改成4h就随意移除7天历史重叠的考虑。验证/测试按连续起报覆盖正式指标，不能仅抽离散行算一个代理分数。

### 未知尾部质量下的训练

可靠训练输入生成两类受扰动视图，未来标签保持不变：

1. 显式缺失：随机遮掉历史尾部，模型可见有限值mask。
2. 隐性填补：尾部改为前值保持、过去同一时刻值、仅依赖更早历史的趋势外推、零值或幅度偏移/平滑失真；替换值为有限值，不提供真实扰动mask、长度或类别。干净与隐性填补样本的quality字段同为unknown。

长度候选1/2/4/8点（15min到2h），16点等更严重情形用于压力测试。候选不是线上缺失上限；实际分布未知时保留整类填补方法及未见长度作域外测试。

初始比较无扰动、25%扰动、50%扰动等配方，剩余为干净样本；比例仅是搜索点。第一轮不穷举所有比例×方法，先一个混合配方检查干净性能和鲁棒性折中，再调整。保留完整干净样本，避免模型学会忽略近期历史。

填补函数只可使用假设截断点之前保留的历史及当时可用信息；不能直接用被移除的真尾部或未来标签插值。省级首轮使用总曲线扰动，后续若有站级组成，再模拟部分站延迟/填补后重新聚合，区分局部和系统性故障。

训练目标为同一个预测损失：L=α·L(clean,y)+(1−α)·L(corrupted,y)，可通过采样近似控制计算量；不强制两个视图输出逐点相等，因为信息减少时合理预测可能改变。首轮不做未来标签监督的历史重建任务。

干净验证集与固定扰动压力集分开报告：按填补方法、长度、昼夜、爬坡日、站/省和horizon观察退化曲线。压力集方法和随机种子固定；至少保留部分训练未见扰动。线上分布未知时不把任意等权混合压力分数称为预计线上收益。以干净分数及预先约定的可接受退化共同选点；没有可接受退化阈值时展示折中而不自行指定业务阈值。

沿用 `Model(config)`、`forward(batch_dict, labels=None)`、`.config` 和统一ModelOutput。`.logits/.predictions`均为[B,16]真实功率；`.loss`仅在给标签时计算；`.aux`承载质量和可选中间表示，避免默认返回大量attention矩阵。

## 13. 必要测试与消融

正确性测试：

- B=1与普通batch前向、反向，logits严格[B,16]；
- 改变labels不得改变eval态预测；
- 时间轴和16个lead对齐，尾部缺失不右移历史；
- 显式缺失与有限值区分；隐性填补与真实零值均无额外真值标记，mask失效与all-masked安全；
- 所有未来16点确实进入query/输出通路，不被patch截断；
- 输入功率/容量共同缩放且其它输入不变时，归一预测应按设计保持一致，恢复功率随尺度变化；
- 训练/推理特征转换一致，权重保存重载一致；
- 干净数据、显式尾部缺失、无标记的多长度填补、多天气源缺失的合成小样本smoke；
- 受扰动尾部在所有patch、统计、旁路中一致，模拟扰动标签不进入输入；
- 站级/省级输入适配器的容量和气象聚合口径，省级缺站时coverage与实际匹配；
- 正式评价的同目标时刻16个lead、完整日和缺失预测计分回归。

实验顺序：

1. 保留旧M4的16点可比较基线（可使用原192点输出的前16点，单独标明训练目标不同），另训合法patch尺寸的16点直接适配基线；TabM同数据评测作参考。
2. Mojito-small：单尺度最近96点patch4、未来query解码，检验输出条件化。
3. 加慢尺度672/96，检验长历史是否有增益。
4. 去掉/恢复raw近期旁路，检验局部状态表达。
5. 分别做归一化、解码器self-attention、可选先验、容量/站点特征消融。

质量鲁棒性先在同一精简结构上比较“仅干净训练/显式缺失增强/显式＋隐性填补增强”，再与固定丢弃末2/4点方案配对比较。站级和省级各自有上述基线，不将两个实体层级的提升混为一个分数。

正式候选固定多种子、配对站日比较。旧M4和Mojito对比存在多个结构变化，不能只跑二者就断言某一个组件有效。是否保留复杂分支取决于收益、最差站退化、缺测鲁棒性和推理成本，而非组件数量。

## 14. 参考与解释边界

- [PatchTST](https://arxiv.org/abs/2211.14730)：patch编码参考；M4已有的跨变量联合attention是本项目的具体实现，不能误称仍为原版通道独立。
- [TiDE §4.2](https://arxiv.org/html/2304.08424v4#S4.SS2)：未来协变量直达输出头的结构参考。
- [TimeXer](https://arxiv.org/abs/2402.19072)：目标历史与外生变量融合的参考；本文未来query decoder并不是逐字复现TimeXer。
- [GRU-D](https://www.nature.com/articles/s41598-018-24271-9)：显式missing mask和时间间隔用于缺测建模的参考；这种机制依赖缺测信息，不能解决无标记填补的可辨识性问题。Mojito不采用GRU-D骨干。
- [DeepAR](https://arxiv.org/abs/1704.04110)：跨序列共享模型和类别embedding的参考，不代表站点ID在本项目必然有效。
- [Solar Position Algorithm](https://midcdmz.nlr.gov/spa/)：由位置和时间计算太阳天顶角、方位角的参考。

这些论文支持模块设计有研究先例，不证明Mojito在本项目优于M4或TabM。本文中的窗口、宽度、层数和优化器参数都是首轮试验起点。

当一段填补序列与某种真实功率状态数值相同，且没有上游元数据时，模型无法保证区分两种来源。设计目标是降低对错误尾部的敏感性，不能承诺识别任意填补或恢复被丢失的信息。未来能获得真实数据治理记录时再加入监督，不以此作为当前架构运行的前提。
